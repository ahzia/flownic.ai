# Runbooks

Operational procedures for the Flownic MVP pilot. Add a runbook when a founder
must perform a repeatable production or pilot action safely.

Suggested first runbooks (create when the related feature ships):

- Pilot session day checklist
- No-show / replacement handling
- Report generation retry / human review
- User deletion request
- Provider outage fallback (media / AI / email)
- Abnormal AI or media spend response
